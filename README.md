# 🇮🇹 ItalyBot — Telegram-бот «Поступление в Италию»

FAQ-бот-консультант для студентов, поступающих в итальянские вузы.
Отвечает на вопросы по темам **Поступление / Стипендии / Виза D / По приезде**,
понимает свободные вопросы (локальный fuzzy-поиск, без ИИ и внешних ключей),
двуязычный (**RU/EN**), с админ-панелью для пополнения базы без перезапуска.

## Логика (как в ТЗ)

```
/start → выбор языка → главное меню → вопрос студента → поиск по базе
        → готовый ответ (или «может, вы имели в виду…») → кнопки для новых действий
```

- **Точное совпадение** → сразу ответ.
- **Похоже** → список вариантов «Может, вы имели в виду: …».
- **Ничего не найдено** → «Пока нет информации, уточните вопрос или выберите тему».

## Стек

- Python 3.12+ (протестировано на 3.14)
- [aiogram 3.x](https://docs.aiogram.dev/) — Telegram Bot API, async
- Поиск — стандартный `difflib` + лёгкий стеммер (свой, в `search.py`)
- База знаний — обычный `data/knowledge_base.json` (RU/EN)

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env      # вставьте BOT_TOKEN от @BotFather и свой ADMIN_IDS
python bot.py
```

`.env`:
```
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=ваш_telegram_id   # узнать: @userinfobot, несколько — через запятую
```

## Команды

| Команда   | Что делает                                  |
|-----------|---------------------------------------------|
| `/start`  | Приветствие + выбор языка                   |
| `/menu`   | Главное меню                                |
| `/admin`  | Админ-панель (только для ID из `ADMIN_IDS`) |
| `/cancel` | Отменить текущий шаг (например, добавление) |

## Структура

```
bot.py                     # точка входа, запуск polling
config.py                  # токен и админы из .env
i18n.py                    # тексты интерфейса RU/EN
storage.py                 # загрузка/сохранение базы и языков пользователей
search.py                  # локальный fuzzy-поиск (стеммер + coverage/difflib)
keyboards.py               # inline-клавиатуры и callback-данные
states.py                  # FSM-состояния (вопрос, добавление Q&A)
utils.py                   # помощники (язык пользователя, формат ответа)
handlers/
  common.py                # /start, язык, меню, ответ по кнопке
  topics.py                # темы и вопросы внутри темы
  ask.py                   # свободный вопрос → поиск
  admin.py                 # добавление Q&A + статистика
data/
  knowledge_base.json      # база вопросов/ответов (редактируется вручную или из /admin)
  users.json               # выбранные языки (создаётся автоматически, в .gitignore)
```

## Как пополнять базу

**Через бота:** `/admin` → «➕ Добавить Q&A» → выбрать тему → ввести вопрос/ответ (RU и EN)
→ ключевые слова. Сохраняется сразу в `knowledge_base.json`, перезапуск не нужен.

**Вручную:** отредактируйте `data/knowledge_base.json` — каждый элемент `faq`:
```json
{
  "id": "уникальный-id",
  "topic": "admission | scholarship | visa | arrival",
  "question": { "ru": "…", "en": "…" },
  "answer":   { "ru": "…", "en": "…" },
  "keywords": ["ключевые", "слова", "keywords"]
}
```
`keywords` усиливают fuzzy-поиск (по ним бот тоже находит вопрос).
